# 2026-09-25 : Découverte de GitHub et organisation du projet

**Séance :** planifiée · **Durée :** 3 h

## Travail réalisé

- **Découverte de GitHub :** Connexion à la plateforme, récupération des accès et exploration des fonctionnalités principales pour comprendre comment travailler en équipe sur un projet commun.

- **Prise en main de la documentation :** Utilisation de Visual Studio Code pour modifier les fichiers Markdown. Découverte de la structure des pages, du frontmatter et de l'organisation des fichiers du journal de bord.

- **Organisation du groupe :** Discussion avec les autres membres de l'équipe pour répartir les tâches selon les compétences de chacun. Les domaines concernés sont la conception mécanique, l'électronique, la programmation et l'intégration des différents éléments.

## Objectifs de la séance

- **Centraliser les informations :** GitHub permet de regrouper les fichiers du projet au même endroit et de suivre les modifications apportées par les membres de l'équipe.

- **Garder une trace du travail :** La documentation régulière permet de retrouver les décisions prises, les idées étudiées et les étapes réalisées. Elle sera également utile pour préparer le rapport technique du second semestre.

- **Améliorer la collaboration :** La répartition des responsabilités permet à chaque membre d'avancer sur sa partie tout en facilitant la coordination entre les différents domaines techniques.

## Reste à faire

- Effectuer des recherches sur les différentes architectures possibles pour notre machine.
- Réfléchir à plusieurs solutions de conception et comparer leurs avantages et leurs inconvénients.
- Identifier les premiers composants et les contraintes techniques à prendre en compte.
